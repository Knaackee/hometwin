# Categories

Use these folders below `generic/` or `manufacturers/<maker>/`. Add a new sub-category only if none fits, and mention it in the pull request.

| category | examples |
|---|---|
| `furniture/seating` | sofa, armchair, chair, stool, bench |
| `furniture/tables` | dining table, coffee table, desk, side table |
| `furniture/storage` | shelf, wardrobe, sideboard, chest of drawers, TV bench |
| `furniture/beds` | bed, bunk bed, cot, nightstand |
| `furniture/outdoor` | garden chair, lounger, parasol, garden table |
| `kitchen/cabinets` | base unit, wall unit, tall unit, island |
| `kitchen/appliances` | fridge, oven, dishwasher, hob, extractor, coffee machine |
| `bathroom` | toilet, washbasin, bathtub, shower, towel radiator, mirror cabinet |
| `lighting/ceiling` | ceiling light, pendant, spot, track |
| `lighting/wall` | wall light, outdoor wall light |
| `lighting/floor` | floor lamp, arc lamp |
